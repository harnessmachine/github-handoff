# GitHub Handoff

**Русскоязычный skill, который сам сохраняет прогресс AI-сессии в GitHub Issue.**

В конце работы достаточно написать:

```text
Зафиксируй прогресс.
```

Skill сам:

- определит текущий GitHub-репозиторий;
- найдёт Issue текущей задачи;
- создаст её, если Issue ещё нет;
- запишет компактный handoff;
- вернёт готовый запрос для нового чата.

Не нужно заранее создавать Issue, искать её URL или заполнять шаблон.

## Главная идея

```text
описание Issue = что нужно сделать
handoff-комментарий = где остановились
новый чат = читает GitHub и продолжает
```

GitHub Issue здесь не «магическая память» модели. Это облачный источник контекста, который видят человек и разные AI-агенты.

## Откуда появилась идея

Skill вдохновлён [`handoff` Matt Pocock](https://github.com/mattpocock/skills/tree/main/skills/productivity/handoff).

Оригинальный skill превращает текущий разговор в компактный переносимый документ. `github-handoff` сохраняет тот же тип контекста в GitHub Issue.

## Установка

Для Codex:

```bash
git clone https://github.com/harnessmachine/github-handoff.git ~/.codex/skills/github-handoff
```

Для Claude Code:

```bash
git clone https://github.com/harnessmachine/github-handoff.git ~/.claude/skills/github-handoff
```

После установки перезапустите сессию, если агент не обнаружил skill автоматически.

## Что понадобится

- GitHub-репозиторий с включёнными Issues;
- AI-агент с поддержкой skills;
- доступ агента к GitHub через connector, API или авторизованный `gh` CLI.

## Использование

В конце сессии:

```text
Используй $github-handoff и зафиксируй прогресс.
```

Агент найдёт или создаст Issue, запишет handoff и вернёт готовый запрос с реальной ссылкой. Вставьте его в новый чат:

```text
Используй $github-handoff и продолжи работу по этой задаче:
https://github.com/OWNER/REPO/issues/123
```

В нужном репозитории можно попросить и без URL:

```text
Используй $github-handoff и продолжи последнюю сохранённую задачу.
```

## Границы

Skill намеренно не управляет GitHub Projects, labels, milestones и полным бэклогом.

Если репозиторий или целевая задача действительно неоднозначны, он задаст один короткий вопрос. В обычном сценарии вопросов нет.

## Безопасность

Не сохраняйте в GitHub Issue токены, пароли, cookies, содержимое `.env`, персональные данные, полные приватные разговоры и большие логи.

Перед использованием проверьте, публичный репозиторий или приватный.
